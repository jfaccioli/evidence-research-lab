# Workstream F — Scientific Meta-Research (permanent)

**Status:** Permanently active alongside discovery, capability, and ops workstreams.  
**Authority:** Standing Research Director Directive + this workstream order.  
**Objective:** Continuously improve the lab’s *ability* to discover genuine edges — **not** to invent signals by copying public “elite firm” narratives.

## What this is

Study **published** scientific, engineering, and operational practices from:

- quant funds / market makers (public process only)  
- academic finance & statistics  
- ML / time-series forecasting research  
- quant software engineering  
- experimental design  

**Extract enduring principles** (workflow, validation, multiplicity, lifecycle, prioritisation, ops resilience).  
**Do not** attempt to reverse-engineer proprietary strategies.  
Treat every source as **incomplete evidence**.

## Decision filter (mandatory)

For each principle:

1. Does the lab already implement it?  
2. Expected **scientific** value under *this* mandate (spot, no leverage, frozen gates, small capital)?  
3. Implementation **effort**?  
4. Does it materially raise P(robust edges) or research productivity?  
5. If justified → schedule in living queue; else document “reject / defer”.

**Never implement only because elite firms do.**

## Cadence

- **Continuous** background alongside other work.  
- **Cycle report** after each substantive survey wave: `docs/meta_research/CYCLE_*.md` + update principle ledger.  
- Prefer **one justified capability** per cycle over long essay-only cycles.

## Non-goals

- Softening gates to “match industry”  
- Neural/RL hypothesis generators as the research claim  
- Portfolio construction for multi-strategy books (premature with 0 survivors)  
- Live monitoring stack before APPROVED strategies
