# Research Director Standing Directive — Lab → Product

**Effective:** 2026-07-28  
**Status:** Standing strategic policy (not a one-shot implementation request)

## Objective

Build the most reliable autonomous personal autotrading system that **available scientific evidence can justify**.

Scientific integrity remains non-negotiable. Governance is stable by default — change it only for demonstrated scientific weakness.

## Priority filter (every major task)

1. Increase probability of discovering genuine predictive information?  
2. Move measurably closer to research→autotrading pipeline completeness?  
3. Improve quality/efficiency of scientific discovery?  
4. Reduce a risk current governance cannot already mitigate?  

If all four are **no**, deprioritise.

## Research allocation

Prefer **different mechanisms / information classes**, not parameter clones of exhausted BTC technical space.

Candidate classes (not assumed edges): exchange flows, prediction markets, social PIT, cross-market, on-chain activity, etc. — all through frozen gates.

## Product

Keep path evidence → validated strategy → paper → shadow → tiny live open without redesign.  
Do **not** promote because a trading system is desired.  
Empty APPROVED is a valid system state.

## Amended critical-path note

Lab ops are mature. Default work = **highest-EV new evidence**. Product polish only when it shortens survivor → tiny-live. Continuous product theatre with zero survivors is deprioritised.
