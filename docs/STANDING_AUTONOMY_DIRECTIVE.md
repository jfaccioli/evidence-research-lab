# Standing Autonomy Directive

**Effective:** 2026-07-28  
**Authority:** Human standing order  
**Supplements:** `docs/AUTONOMOUS_CHARTER.md`, Research Director directive, product roadmap

## Proceed without routine approvals

After completing any task or scientific programme, **automatically** determine the next highest-value task on the approved roadmap and continue.

Do **not** pause merely because a milestone finished. Default = continuous autonomous progress.

## Interrupt human only when required

* API keys, credentials, or paid data access  
* Exchange access or live trading  
* Capital allocation  
* Validation threshold / gate changes  
* Personal risk policy changes  
* Major architecture that materially alters the lab  
* Unresolvable Grok–Codex scientific disagreement  
* Multiple reasonable paths that **materially** affect project direction  

## Otherwise continue

Implementation, research, dual-Grok QA, documentation, testing, planning, roadmap execution.

When a programme finishes: update thesis tree, roadmap, programme queue → start next highest-EV approved programme unless externally blocked.

## Objective

Shortest scientifically defensible path to a usable personal autotrading system **without** weakening gates. Optimise for reducing time to first justified tiny-live trial while preserving integrity.
