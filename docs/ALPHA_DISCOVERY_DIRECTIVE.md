# Alpha Discovery Directive

**Effective:** 2026-07-28  
**Complements:** Standing Research Director Directive, Workstream F, Evidence Acquisition Roadmap  
**Primary optimisation target:** discovery of **genuinely new predictive information**

## Mission

Do **not** optimise for more code, datasets, programmes, or infrastructure.

Optimise for increasing P(discover persistent, reproducible information asymmetries that can support trustworthy personal autotrading under frozen gates).

## Think in information advantages

Do not ask: “What dataset should I test next?”

Ask: **“What information advantage might exist that this laboratory cannot currently observe?”**

Datasets are only **vehicles**. Rank by expected value of the **underlying information**, not vendor popularity.

## Permanent Alpha Discovery programme

Continuously survey public literature, methodologies, and historical data *as access to mechanisms*.

For each candidate **information class**:

1. Economic / behavioural mechanism  
2. Historical reconstructibility  
3. Point-in-time integrity  
4. Persistence / scientific EV  
5. Acquisition cost  
6. Comparison to lab’s existing evidence  
7. Genuinely new vs exhausted expression  
8. Schedule only if EV justifies effort  

## Elite organisations (public only)

Extract methodology and discipline — **not** proprietary strategies. Implement principles only when justified for *this* lab.

## Self-critique (recurring)

> If a world-class quant research org started this lab today, what would they improve first?

Treat answers as **hypotheses requiring evidence**, not gospel.

## Research economy

- One new information class ≫ fifty indicator variations  
- One strong causal hypothesis ≫ hundreds of weak searches  
- Scientific insight ≫ engineering activity  
- Reject busywork  

## Human interaction

Do not interrupt merely because no programme is running. Keep improving discovery capacity. Interrupt only for real external dependencies (keys, paid data, capital, policy).

## Success metric

**P(real, persistent edge under our standards)** — not repo size, programme count, or complexity.

Every major decision:

> Will this materially improve our ability to discover robust predictive information?
